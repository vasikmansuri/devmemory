# Troubleshooting

| Symptom                                         | Fix                                                                                                                                                                                                   |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PROJECT_NOT_INITIALIZED` (exit 4)              | Run `devmemory init` in the project root, or pass `--project <dir>`. For MCP you can add `--init`.                                                                                                    |
| `DB_BUSY` (exit 6)                              | Another process is holding a write lock. Retry, or raise `DEVMEMORY_BUSY_TIMEOUT_MS`.                                                                                                                 |
| `DB_CORRUPT` (exit 6)                           | Run `devmemory doctor`. Restore a `devmemory.db.bak-*` backup, or move the database file aside to start fresh.                                                                                        |
| `DB_VERSION_UNSUPPORTED`                        | The database was created by a newer DevMemory. Upgrade DevMemory.                                                                                                                                     |
| Search finds nothing                            | Search matches keywords, not meaning, so use words that appear in the memory. Expired, archived and superseded memories are hidden by default: try `--include-expired` or `--status active,archived`. |
| `doctor` reports `fts_index_consistency` failed | Run `devmemory doctor --repair`.                                                                                                                                                                      |
| `doctor` reports `file_permissions` failed      | Run `chmod 700 ~/.devmemory && chmod 600 ~/.devmemory/devmemory.db`.                                                                                                                                  |
| The MCP server doesn't show up in Claude Code   | Check that `devmemory` is on your `PATH`. Run `claude mcp get devmemory`. Approve project-scoped servers by starting `claude`.                                                                        |
| `better-sqlite3` fails to install               | No prebuilt binary exists for your platform or Node version. Install a C++ toolchain (Windows on Node 22 is known to need one), or use Node 24 or newer.                                              |
| You moved your project directory                | Project identity is the directory path. Run `devmemory export -o m.json` in the old location first, then `devmemory init` and `devmemory import m.json` in the new one.                               |
| You need debug output                           | Set `DEVMEMORY_LOG_LEVEL=debug`. Logs go to stderr and never include memory content.                                                                                                                  |
