# Roadmap

## 0.2

- Optional local embeddings (for example ONNX models) behind `registerEmbeddingProvider`, with hybrid keyword and semantic ranking. Retrieval changes will report evaluation numbers before and after.
- Optional trigram tokenizer for CJK text.
- A `devmemory project move` command to relink a project after its directory moves.
- End-to-end verification of the Cursor integration.

## Later

- Opt-in encryption at rest.
- Memory consolidation suggestions (merging near-duplicate memories), always confirmed by the user.
- An MCP resources and prompts surface.

## Out of scope for v1

- Dashboard.
- Cloud sync.
- Mandatory AI-powered memory extraction.
